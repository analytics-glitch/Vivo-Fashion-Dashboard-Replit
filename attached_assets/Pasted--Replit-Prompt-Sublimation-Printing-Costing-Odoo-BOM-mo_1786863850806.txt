### 5b. Derived dimensions (read-only)
```
Print width = Fabric width − 2 × (margin_cm / 100)          = 1.47 m
Printed area (ink basis) = Metres × Print width              = 458.346 m²
Fabric area (weight/paper basis) = Metres × Fabric width     = 464.582 m²
Fabric weight = Fabric area × GSM / 1000                     = 65.0415 kg
Machine time (decimal) = hours + minutes/60                  = 5.2167 hrs
```

### 5c. Ink — tile-based derivation (THIS is the ink mechanism; reproduce exactly)
The design’s ink coverage is measured from a **test tile**: a small printed square of known size, with the ink used per colour read from the printer/RIP.

Editable inputs:
- **Tile width** and **Tile height** in cm (default 60 × 60).
- **Ink cost per ml** (default 2.75 KES/ml).
- Per colour, **Actual ink used on the tile (ml)**: Cyan 0.01, Yellow 0.13, Magenta 0.09, Black 0.02.

Calculations:
```
Tile area (m²) = (Tile width_cm × Tile height_cm) / 10000        = 0.36 m²
Per-colour coverage (ml/m²) = colour tile ml ÷ Tile area
    Cyan 0.0278 · Yellow 0.3611 · Magenta 0.2500 · Black 0.0556  (total 0.6944 ml/m²)
Per-colour run cost (KES) = coverage × Printed area × Ink cost/ml
Ink subtotal = SUM of the four colour costs                       = 875.31
```
Show a small readout: total tile ink = 0.25 ml over 0.36 m². Display each colour’s coverage and run cost in a 4-row table.

### 6a. Conversion factors
```

Metres per kg = 1 / Weight per linear metre               = 4.7939 m/kg

Printed m² per kg = Fabric m²/kg × Print ratio            = 7.0470 m²/kg
```
