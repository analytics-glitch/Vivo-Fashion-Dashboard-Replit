Context: This BI dashboard (api_pg.py, FastAPI + uvicorn, Neon Postgres in prod) has several endpoints that recompute expensive aggregates over the full all_sales table (~1.5M rows) on every cold cache. Under real load these cold queries run 30-50+ seconds and, when the cache is empty, pile up and stall the whole dashboard. We already fixed the customer endpoints by routing them to pre-aggregated rollup tables (rollup_customer_lifetime, rollup_customer_first_purchase) behind a _rollup_fresh() gate, refreshed by the sync loop. That pattern works well. Now do the same for the OTHER heavy queries.
