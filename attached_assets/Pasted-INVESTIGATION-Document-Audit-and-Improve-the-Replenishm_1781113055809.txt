SECTION 2: WHAT THE PROCESS SHOULD IDEALLY DO
Based on retail fashion best practices and the data available, document what a complete replenishment and IBT system should do:
Replenishment should:

Identify styles/SKUs that are running low across all stores
Calculate demand-based reorder quantities using actual sales velocity
Account for lead times, minimum order quantities, and supplier constraints
Prioritise by sales contribution, weeks of cover, and season timing
Distinguish between warehouse replenishment (produce/order more) and store replenishment (move from warehouse to store)
Flag dead stock and overstocked styles separately
Output a purchase order / production request format
Account for size curve — replenish in the right size ratio based on historical sales mix

IBT should:

Identify imbalances where Store A has excess stock of a style and Store B has a stockout or near-stockout of the same style
Account for store tier, demographics, and sales velocity per location
Avoid moving slow-moving stock from one store to another slow store
Calculate the optimal transfer quantity (not just binary yes/no)
Consider size run integrity — avoid breaking a complete size run at the source store
Flag "late IBT" where a recommended transfer hasn't been actioned within X days
Track transfer history and measure outcomes (did the receiving store sell the transferred units?)
Group transfers by source store to minimise logistics trips

Improvements to cover:

Weeks of Cover formula — current formula vs recommended formula using rolling 8-week average sales velocity instead of static period
Dynamic reorder point — incorporate lead time (default 4 weeks for Vivo production) into reorder trigger
Size curve logic — when recommending replenishment quantity, split by size using historical sales mix (e.g. if S=30%, M=40%, L=20%, XL=10% of sales, recommend quantities in that ratio)
IBT scoring model — replace binary yes/no with a score (0-100) based on: source store excess weeks of cover, destination store stockout risk, style sell-through rate, store sales velocity match
Size run integrity — add a check: if transferring units would leave source store with a broken size run (missing a core size), reduce transfer quantity or skip
Seasonal adjustment — weight recent 4-week sales higher than older weeks when calculating velocity (exponential weighted average)
Dead stock flag — flag any SKU with >16 weeks of cover and <5% sell-through in last 8 weeks as dead stock, exclude from IBT recommendations
Chronic stockout detection — flag styles that have been at <2 weeks of cover for 3+ consecutive weeks as chronic, escalate priority
