---
name: Merch store size analysis
description: Business and metric rules for comparing store size performance with network benchmarks.
---

Store size analysis must show selected-store SOR and current SOH by size together. The network comparison is calculated per size from aggregate units sold ÷ (aggregate units sold + aggregate SOH), rather than averaging each store's SOR percentage. SOH share is the selected store's size SOH divided by its total size-analysis SOH.

**Why:** Merchandising teams use the pair to validate size-range requests: high SOR with near-zero SOH supports replenishment, while low SOR with healthy SOH challenges an availability claim.

**How to apply:** Keep the size universe, brand/subcategory scope, country scope, active-style gate, date window, and store-vs-network inventory exclusions identical across both charts.
